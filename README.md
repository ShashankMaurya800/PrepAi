# 🤖 PrepAI – Smart Mock Interview Platform

PrepAI is a full-stack mock interview platform developed using the MERN Stack. It helps students prepare for placement interviews by simulating real interview experiences with technical and HR questions, speech-to-text support, performance analytics, PDF reports, and interview history.

---

## 🚀 Features

* User Registration & Login
* Secure Authentication
* Dashboard with Interview Statistics
* Multiple Interview Categories

  * HR
  * Java
  * SQL
  * DSA
  * JavaScript
  * React
  * Node.js
* 350+ Curated Interview Questions
* Random Question Generation
* 30-Second Timer per Question
* Speech-to-Text Answer Input
* Automatic Answer Evaluation
* Performance Score
* Detailed Feedback
* Interview Summary
* PDF Report Generation
* Interview History
* Performance Trend Chart
* Responsive User Interface
